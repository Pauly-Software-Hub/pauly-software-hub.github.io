JobReady

Build your CV, check how well you match a job, and track every application

JobReady helps job seekers: build a proper CV and print it or save it as a PDF, paste a job advert to see how well you match it, write a cover letter and summary for that job, and keep track of every application with reminders to follow up.

What it does

  • CV builder - print or save as PDF
  • Check how well you match a job advert
  • Cover letters and a summary written for each job
  • Track every application
  • Reminders to follow up

Good to know

  • For Windows 10 and Windows 11 – one program file, nothing else to install.
  • Free demo mode, then a Monthly or Yearly subscription (EFT or card).
  • Updates download and install by themselves.
  • Made and supported in South Africa by Paul Maritz.
